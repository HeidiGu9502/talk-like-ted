# 起念 QǐNiàn

「把想法说清楚」表达力训练小游戏的移动端优先 Web H5 MVP。当前版本无需安装依赖或构建工具，可直接在浏览器打开 `index.html`。

## 已实现

- 首页成长进度、连续训练天数和最近训练回顾
- 观点三问、经历四步两种训练模板
- 起念输入、灵感提示、逐问回答、跳过、重答和提前成稿
- 可编辑结构化成稿、复制文本、生成 PNG 进化卡
- 本地想法库（最近 20 局）、六枚基础徽章、等级经验和设置
- 无后端时使用内置固定追问，完整训练流程可离线运行

## 运行

直接用浏览器打开 `index.html`。如需本地 HTTP 服务，可在此目录运行：

```sh
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。训练数据保存在当前浏览器的 localStorage；清除浏览器站点数据会删除本地记录。

## DeepSeek 代理约定

浏览器端**不得存放 DeepSeek API Key**。将来接入 AI 时，应实现自有后端代理，并由前端向同源 `/api/coach` 发请求。建议请求体：

```json
{
  "mode": "question",
  "template": "opinion",
  "thought": "初始想法",
  "answers": ["已完成的回答"],
  "round": 1
}
```

问题模式返回 `{ "transition": "简短肯定", "question": "一次只问一个问题" }`；成稿模式可返回 `{ "blocks": [{ "label": "观点", "text": "用户原话" }] }`。代理端负责鉴权、密钥保管、限流和内容安全审核。前端在代理不可用时应继续使用 `app.js` 内置问题与本地成稿逻辑，不阻断训练。

本版本保持免费 MVP，不实现付费墙。数据只保存在本地浏览器，不提供账号同步。
